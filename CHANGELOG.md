# Changelog

All notable changes to this project are documented in this file.

## 0.1.0 — 2026-11-07

- Initial public release as **RPGM TextPort MV/MZ**.
- Offline export/import of standard RPG Maker MV/MZ `data/*.json` files.
- Supports dialogue, choices, database, system, map, common event, and troop
  text.
- `--split` export for batch translation.
- `--dry-run` import and timestamped backups before writing.
- Placeholder and control-code mismatch warnings.
- English and Simplified Chinese READMEs with a one-click language switch.
- No injection, no network access, no external dependencies.
